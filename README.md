# Projeto MedIR-RAG - Recuperação de Informação em Bases de Texto (RIBT)

Repositório dedicado ao projeto "MedIR-RAG" desenvolvido no âmbito da unidade curricular de Recuperação de Informação em Bases de Texto do Mestrado em Engenharia Informática da Universidade de Évora.

## Objetivos do Projeto
Desenvolvimento, afinação e avaliação experimental de um pipeline completo de Recuperação de Informação Multiestágio integrado com Geração Fundamentada (Retrieval-Augmented Generation - RAG) no domínio da literatura médica[cite: 20].

## Estrutura do Repositório
* **[Milestone 1](./Milestone_1)**: Indexação, Baseline Lexical e Avaliação Tradicional.(Em desenvolvimento)
* **Milestone 2**: Recuperação Densa, Fusão Híbrida e Re-ranking com LoRA (Não iniciado).
* **Milestone 3**: Pipeline RAG, Quantização QLoRA e Avaliação de Geração (Não iniciado).
